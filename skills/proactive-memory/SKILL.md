# Proactive Memory Skill

Proactive memory activation system — surfaces relevant memories before you ask.

## Commands

### `--status`
Show current proactive memory status.

### `--topics`
Show detected topics in current conversation.

### `--suggest`
Get proactive memory suggestions for current conversation.

### `--feedback [memory-id] [--helpful|--rejected]`
Record feedback on a surfaced memory.

### `--stats`
Show feedback statistics (top performers, weights).

### `--enable`
Enable proactive memory surfacing.

### `--disable`
Disable proactive memory surfacing.

### `--cores`
Show currently loaded Context Cores.

### `--load-core [core-id]`
Manually load a Context Core.

### `--switch-project [path]`
Switch project context (triggers core reload).
