## MemPalace 源码分析 - 完成

### 项目概述
- **位置**: `E:\mempalace-main`
- **语言**: Python
- **存储**: ChromaDB + SQLite (本地)
- **Benchmark**: 96.6% LongMemEval R@5 (零 API 调用)
- **特点**: Palace 宫殿结构 + Temporal Knowledge Graph

### 核心架构

#### Palace 存储 (ChromaDB)
```
Wing (人/项目) → Room (主题) → Drawer (原始内容)
  ├── Hall (记忆类型): facts/events/discoveries/preferences/advice
  └── Tunnel (跨 Wing 连接)
```

#### 4层记忆架构
```
L0: Identity (~50 tokens) — ~/.mempalace/identity.txt
L1: Essential Story (~500-800 tokens) — 自动生成
L2: On-Demand (~200-500 tokens) — 按 Wing/Room 过滤
L3: Deep Search — 语义搜索
```

#### Knowledge Graph (Temporal KG)
```
Entity → Predicate → Entity (valid_from / valid_to)
SQLite 本地存储，零云依赖
```

### 核心文件
| 文件 | 功能 |
|------|------|
| `palace.py` | ChromaDB 操作封装 |
| `knowledge_graph.py` | 时态知识图谱 |
| `searcher.py` | 语义搜索 |
| `miner.py` | 项目 Mining |
| `convo_miner.py` | 对话 Mining |
| `layers.py` | 4层记忆栈 |
| `dialect.py` | AAAK 压缩方言 |
| `entity_detector.py` | 实体自动检测 |
| `palace_graph.py` | 图遍历 |
| `mcp_server.py` | MCP 工具服务 (19 tools) |
| `cli.py` | CLI 命令行 |
| `config.py` | 配置管理 |

### MCP 19 工具
- **Palace 读**: status, list_wings, list_rooms, search, check_duplicate
- **Palace 写**: add_drawer, delete_drawer
- **KG**: kg_query, kg_add, kg_invalidate, kg_timeline, kg_stats
- **导航**: traverse, find_tunnels, graph_stats
- **Diary**: diary_write, diary_read

### Auto-Save Hooks
- `mempal_save_hook.sh` — 每15条消息保存
- `mempal_precompact_hook.sh` — 压缩前紧急保存

### 可借鉴设计
