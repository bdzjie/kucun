### 新增模块说明

**skill_plugin.ts** — Skill 插件标准接口
- `SkillPlugin` 接口：id/name/version/priority/patterns/languages/detect()
- `SkillPluginRegistry` 事件发射器：register/detectAll/getTools
- 内置插件：`CLIToolPlugin`(priority=0) + `FilePatternPlugin`(priority=1)
- 优先级队列自动排序，priority=0 最高

**lineage.ts** — 记忆依赖图（DAG）
- `MemoryLineage` 类：addEdge/getOutgoing/getIncoming/getPath/getAncestors/getDescendants
- 关系类型：reads/writes/invokes/derives/cites/references
- BFS 遍历：影响分析 + 来源追溯
- 追加日志（WAL）持久化

**feed.ts** — Agent 协作消息 Feed
- `AgentFeed` 类：send/reply/assignTask/markRead/resolve
- 消息类型：request/response/handoff/alert/notification/thread_reply
- Thread 支持：task/context/alert/general
- 广播事件：`task_assigned`/`memory_updated`/`routing_feedback`
- 追加日志持久化

**ontology_v2.py** — 版本历史 + 软删除
- `EntityVersion` dataclass：新增 `version`/`prev_version`/`is_deleted`/`extension`
- SQLite 存储：`entities` + `version_history` + `relations`
- 操作：create/update/soft_delete/restore/get_history/list_entities
- Extension 字段：OpenMetadata 风格自由元数据
- CLI：`import`/`stats`/`deleted`/`history <entity_id>`

**agent_audit.py** — Skill 质量测试框架
- 10 个内置测试（invest/expert_router/generic）
- 断言类型：field in/range/min/max/type/minLength/maxLength
- 运行：`python -m modules.agent_audit --skill invest --json`
- 测试结果：10/10 通过 ✅
