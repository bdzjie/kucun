## GenericAgent 深度分析（lsdefine/GenericAgent）

**分析日期**: 2026-04-18 下午
**源码**: GitHub + API 逐文件读取
**定位**: 自进化 Agent 框架，技能自生长

### 核心架构

```
GenericAgent (~3K 行核心)
├── agent_loop.py        — ~100行 Agent Loop（Generator-based 流式）
├── ga.py                — Handler + 9个原子工具
├── agentmain.py         — GenericAgent 主类 + 多模型支持
├── llmcore.py           — ~2000行，多后端 LLM 封装
├── reflect/
│   ├── autonomous.py    — 30分钟空闲触发自主探索
│   └── scheduler.py     — 定时任务调度（cron 表达式）
└── memory/              — 4层记忆体系
```

### 关键设计：summary 标签

```xml
<thinking> 分析当前情况... </thinking>
<summary> 简洁快照（<30字）：工具结果+下一步意图 </summary>
<tool_use>{"name": "code_run", "arguments": {...}}</tool_use>
```

**关键洞察**: `summary` 标签是"物理快照"，要求模型输出工具结果+意图的精确描述，供后续轮次参考。

### 行动验证写入原则（最重要）

```
"No Execution, No Memory"
→ 任何写入 L1/L2/L3 的信息必须来自成功执行的工具结果
→ 禁止 LLM 自行推断后写入（防止幻觉记忆）
```

### 4层记忆

| 层级 | 存储 | Token 预算 | 内容 |
|------|------|-----------|------|
| L1 | `global_mem_insight.txt` | < 1k tokens | 关键词→L2/L3 定位指针 + 浓缩规则 |
| L2 | `global_mem.txt` | 可伸缩 | 事实、路径、验证记录（按 ##[SECTION] 分割） |
| L3 | `memory/*.md/*.py` | 无限制 | 任务特定 SOP（自动结晶生成） |
| L4 | `L4_raw_sessions/` | 百万级 | 原始会话归档（Scheduler 每12小时压缩） |

### L1/L2 同步规则

```
L2/L3 新增 → L1 添加"关键词→定位"映射
L2/D3 删除 → L1 删除对应关键词
L2/L3 修改 → L1 关键词不变，只更新值
```

### 自进化机制（Skill Crystallization）

```
第一次任务 → 完整探索（安装依赖、编写脚本、调试）
           ↓
           结晶为 SOP（写入 L3）
           ↓
           L1 添加关键词指向

第二次相似任务 → 直接 recall SOP → 一行调用
```

### 每10轮重置 tools

```python
if turn%10 == 0: client.last_tools = ''
```

防止上下文过长导致 tools schema 在 prompt 中位置退化。

### MixinSession 容错路由

```python
# 失败后自动切换到下一个 session
# 300秒后 spring-back 回到主模型
```
