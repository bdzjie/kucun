### 4. Context Core 打包模式落地

**新增**：`modules/knowledge/memory_integration.mjs`（9805 字节）

统一整合所有记忆模块：

```
User Query
    ↓
memory_rag (概念抽取 + 关系感知检索)
    ↓
memory_graph (三元组存储)
    ↓
memory_provenance (来源追溯)
    ↓
ebbinghaus_memory (Wing/Room/Hall)
    ↓
context_core (可移植打包)
    ↓
context_core_loader (项目自动加载)
    ↓
memory_feedback (反馈权重)
```

**核心类**：`MemoryIntegration`（单例模式）

**暴露 API**：
- `attachSource()` — 来源标注
- `addTriple()` / `extractAndGraph()` — 知识图谱写入
- `traverseGraph()` / `toMermaid()` — 图查询和可视化
- `retrieve()` / `answer()` — GraphRAG 检索
- `ingest()` — 内容摄取
- `createCore()` / `exportCore()` / `loadCore()` / `mergeCore()` — Context Core 生命周期
- `recordRetrievalUsed/Rejected()` — 反馈记录
- `getBoostedWeight()` / `getTopPerforming()` — 权重查询
- `getProactiveSuggestions()` / `detectTopics()` — 主动推送
- `bm25Search()` — L3 深搜
- `fullQuery()` — 组合查询流
