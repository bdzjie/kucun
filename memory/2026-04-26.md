## Skills Audit — YAML 解析重写（21:39 UTC）

### 问题

26个 SKILL.md 显示 `triggerCount: 0`，但实际上它们都有 triggers。

**根因**：`extract_frontmatter` 的 YAML 解析逻辑遇到 `---  triggers:` 格式时（关闭 `---` 与 `triggers:` 写在同一行）完全失败。

真实文件格式：
```
---
name: exec-inline
description: Execute inline code
metadata:
  openclaw:
    command-tool: Bash
---  triggers:
    - /exec inline
    - /js
```

### 修复

重写 `extract_frontmatter`（`modules/audit_skills.py`）：

1. 用简单位置扫描 `c.find('\n---', 4)` 替代 `.*?` 正则，避免 DOTALL 模式下 `\n---` 匹配换行而非文件结束的问题
2. 预检测 `---  triggers:` 行内合并：`re.search(r'\n?---([^\n]*)', raw)` 捕获行内内容
3. 限制行内捕获：只匹配连续的 `- ` 项，遇到非项内容停止（避免 body 中 markdown 列表被误捕获）
4. 新增 `test_inline_triggers_single` 边界测试
