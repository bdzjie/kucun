### 本次完成

#### L4 Archiver Cron — 独立方案 ✅

**问题**: gateway cron 需要 pairing（`operator.admin scope`），jobs.json schema 不兼容导致 gateway crash。

**解决方案**: `scripts/memory_cron.mjs` — 纯 Node.js 定时器，不依赖 gateway。

```
node scripts/memory_cron.mjs              # 前台运行
node scripts/memory_cron.mjs --daemon    # 守护进程
node scripts/memory_cron.mjs --once      # 单次执行
```

**功能**:
- L4 归档间隔: 12小时（GenericAgent 启发）
- SOP 检查间隔: 1小时
- Cron State: `~/.openclaw/memory/L4_raw_sessions/cron_state.json`
- 实际运行: ✅ 归档 5 条记忆到 all_histories.txt

**原理**:
```javascript
// 使用 Node 内置 setInterval，不依赖任何外部调度
setInterval(tick, 60 * 60 * 1000); // 每小时检查一次
// tick() 内判断是否到达 L4 归档时间窗（12h）
```

**vs Gateway Cron**:
| 特性 | Gateway Cron | memory_cron.mjs |
|------|-------------|-----------------|
| 需要 pairing | ✅ | ❌ |
| jobs.json schema | 需兼容 | 无 |
| 持久化状态 | gateway 内 | cron_state.json |
| 进程管理 | gateway 进程 | 独立进程 |
| 定时精度 | 高 | 中（每小时检查）|
