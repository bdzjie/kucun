#### L4 Archiver Cron — 独立方案 ✅

**问题**: gateway cron 需要 pairing（`operator.admin scope`），jobs.json schema 不兼容导致 gateway crash。

**解决方案**: `scripts/memory_cron.mjs` — 纯 Node.js 定时器，不依赖 gateway。

```
node scripts/memory_cron.mjs              # 前台运行
node scripts/memory_cron.mjs --daemon    # 守护进程
node scripts/memory_cron.mjs --once      # 单次执行
```

**功能**:
- L4 归档间隔: 12小时（GenericAgent 启发）
- SOP 检查间隔: 1小时
- Cron State: `~/.openclaw/memory/L4_raw_sessions/cron_state.json`
- 实际运行: ✅ 归档 5 条记忆到 all_histories.txt

**原理**:
```javascript
// 使用 Node 内置 setInterval，不依赖任何外部调度
setInterval(tick, 60 * 60 * 1000); // 每小时检查一次
// tick() 内判断是否到达 L4 归档时间窗（12h）
```

**vs Gateway Cron**:
| 特性 | Gateway Cron | memory_cron.mjs |
|------|-------------|-----------------|
| 需要 pairing | ✅ | ❌ |
| jobs.json schema | 需兼容 | 无 |
| 持久化状态 | gateway 内 | cron_state.json |
| 进程管理 | gateway 进程 | 独立进程 |
| 定时精度 | 高 | 中（每小时检查）|

## 12:29–13:03 Hermes 深度功能 — 真正集成

### 架构问题：Python 模块无法集成到 OpenClaw Runtime

**问题**：所有 Python 模块只能通过 `child_process.spawn` 调用，无法像 JS 模块那样直接 `import` 到 Bun/Node ESM Runtime。

**根本原因**：OpenClaw Runtime（`dist/gateway/`）没有 Python 执行层。

### 解决方案：纯 TypeScript 重写

将核心功能从 Python 迁移到 TypeScript，实现真正集成。

### 新增 TS 模块（已验证）

| 模块 | 行数 | 功能 | 验证 |
|------|------|------|------|
| `modules/search/session_fts.ts` | ~450 | BM25 全文搜索 | ✅ 221消息/2会话，5个搜索结果 |
| `modules/conversation_analyst.ts` | ~370 | 会话分析报告 | ✅ 873消息分析 |

### 关键代码：session_fts.ts

- `rebuildIndex(sessionsDir)` — 内存反向索引
- `search(query, options)` — BM25评分+snippet
- `getSessionSummary(sessionId)` — 会话摘要
- Tokenizer: 简单 Porter stemming + CJK 支持
- BM25参数: k1=1.5, b=0.75

### 关键代码：conversation_analyst.ts

- `generateReport(sessionsDir, recentCount)` — 聚合统计
- `formatReport(report)` — Markdown报告
- Topic提取 + Tool排行 + 会话对比
